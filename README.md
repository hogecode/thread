# 5ch風掲示板アプリケーション

## プロジェクト概要

5ちゃんねる（5ch）のような掲示板機能を備えた Webアプリケーションです。ユーザーはスレッドを作成し、投稿を共有し、他のユーザーと掲示板を通じてコミュニケーションを取ることができます。

## 技術スタック

- **フロントエンド**: Nuxt 3 + Vue 3
- **バックエンド**: Node.js + Express.js
- **データベース**: MySQL 8.0+
- **キャッシング**: Redis（オプション）
- **言語**: JavaScript/TypeScript

## 主要機能

### ユーザー機能
- ユーザー登録・ログイン・ログアウト
- ユーザープロフィール管理
- ユーザーフォロー機能
- ユーザー検索

### スレッド機能
- スレッド一覧表示（カテゴリ別、人気順など）
- スレッド作成
- スレッド検索
- スレッド削除（投稿者・管理者）

### 投稿機能
- スレッド内の投稿表示（ページネーション対応）
- 新規投稿
- 投稿編集
- 投稿削除（投稿者・管理者）
- 投稿検索

### 高度な機能
- ユーザープロフィール表示
- ユーザー間メッセージング機能
- Redis キャッシング
- 全文検索機能
- ページネーション（スレッド一覧、投稿一覧）
- レスポンシブ UI

### 管理機能
- ユーザー管理（有効化・無効化・削除）
- スレッド・投稿の削除
- 報告機能への対応
- ログ管理

## クイックスタート

### 必要な環境
- Node.js 16.x以上
- npm または yarn
- MySQL 8.0以上
- Redis（オプション）

### インストール手順

```bash
# リポジトリをクローン
git clone <repository-url>
cd 5ch-like-bulletin-board

# バックエンドの依存ライブラリをインストール
cd backend
npm install

# フロントエンドの依存ライブラリをインストール
cd ../frontend
npm install
```

### 環境設定

詳しくは `セットアップガイド` をご参照ください。

### 開発サーバーの起動

```bash
# バックエンド（ポート 3001）
cd backend
npm run dev

# フロントエンド（ポート 3000）
cd frontend
npm run dev
```

ブラウザで `http://localhost:3000` にアクセスしてください。
